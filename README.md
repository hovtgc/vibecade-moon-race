# Moon Race

A 3D lunar dirt rally for [VibeCade](https://www.vibecade.si). Two to eight monster Cybertrucks, one long seeded regolith stage, water jugs in the bed. Lowest time wins.

## Play

```bash
npm install
npm run dev
```

Open the local URL Vite prints. Press Start.

- Keyboard: W gas, S brake, A left, D right, Space drift, R reset
- Mouse: move to steer, left click gas, right click brake
- Touch: the buttons along the bottom

## Submit

The VibeCade manifest is [public/xapps.manifest.json](public/xapps.manifest.json). Point a new game at this repo from the [developer portal](https://www.vibecade.si/developers/new).
